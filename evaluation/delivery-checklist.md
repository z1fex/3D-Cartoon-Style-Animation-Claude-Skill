# Delivery checklist

Tick every line before a video goes to the owner.

## Story and text
- [ ] The first line is a claim or question that opens a loop (no scene-setting).
- [ ] The title question is on screen from frame 0 and gone after the hook (2–3 s).
- [ ] Every caption matches the spoken words; the meaning word is big, the surprising word is red italic.
- [ ] Every claim is in the source table; disagreements are hedged.
- [ ] The last line loops into the first frame.
- [ ] The render log names the fonts used (the included ones or licensed brand files), and the owner is told which.

## Picture
- [ ] Framing report: no issues except intended ones (named in the round notes).
- [ ] Jump scan: no flags except caption changes and intended gags.
- [ ] Every frame reviewed by eye against the glitch catalogue.
- [ ] Every number lands as an object on its word; no number shows early.
- [ ] Every gesture lands about 4 frames before its word; every face swap goes through a blink.
- [ ] Real-world things look real; brand colours on clothes, props and sets.
- [ ] No dark or empty frames.

## Sound
- [ ] Every visible action has a sound; no sound without an action.
- [ ] Accents at most about 20 a minute, on story beats.
- [ ] Levels check: accents about −9 dB, foley about −15 dB against the voice; nothing jumps out.
- [ ] Master −14 LUFS (±0.5), true peak ≤ −1.5 dBTP.

## Files
- [ ] 1080×1920, 30 fps, H.264 (BT.709, limited range) + AAC 48 kHz stereo, faststart.
- [ ] `storyboard.png`, `poster.png`, `cue-sheet.txt`, stems, `shots.json`, `framing-report.json` beside the MP4.
- [ ] Round notes written ([template](../templates/round-review-template.md)), including what is still weaker than the reference.
